# Production RAG Service

A document-based Retrieval-Augmented Generation (RAG) application
built using FastAPI, Neon PostgreSQL, Pinecone, local embeddings
and Google Gemini.

## Technology Stack

- Python 3.12
- FastAPI
- Neon PostgreSQL
- Pinecone Vector Database
- BAAI BGE-small-en-v1.5 Embeddings
- Google Gemini 2.5 Flash
- HTML, CSS and JavaScript
- pytest
